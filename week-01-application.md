## 2. Kết quả thực hiện

### Nguyễn Thế Gia Bảo
- Chốt các module Login, Dashboard, Server Inventory, Alerts, Automation Jobs và Audit Log.
- Hoàn thành sơ đồ kiến trúc ứng dụng: trình duyệt đến Flask đến SQLite, Flask đến Prometheus API, Flask đến Ansible.
- Hoàn thành ERD cho users, servers, alerts, automation_jobs và audit_logs, kèm khóa chính, khóa ngoại và quan hệ.
- Hoàn thành wireframe Login, Dashboard, Server list, Server detail, Alert list và Automation job page.
- Hoàn thành Flask skeleton chạy được, schema SQLite và dữ liệu mock.
- Hoàn thành kế hoạch gọi Prometheus API và trigger Ansible. Tuần này chưa thực thi lệnh trên máy thật.
