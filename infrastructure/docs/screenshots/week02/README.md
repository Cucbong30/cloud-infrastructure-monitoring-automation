# hình ảnh triển khai hạ tầng Tuần 2

Thư mục này lưu trữ các ảnh chụp màn hình cho các công việc triển khai hạ tầng trong Tuần 2.

Các nội dung m bao gồm:
- Cấu hình mạng và địa chỉ IP của các máy chủ.
- Kết nối SSH giữa MON01 với WEB01 và APP01.
- Cấu hình WinRM trên WIN01.
- Cài đặt và kiểm tra Nginx.
- Cài đặt và kiểm tra Docker.
- Triển khai workload container trên APP01.
- Cài đặt và kiểm tra Node Exporter.
- Cài đặt và kiểm tra Windows Exporter.
