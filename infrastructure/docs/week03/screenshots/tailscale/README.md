# Tailscale Screenshots

Thư mục này lưu các hình ảnh minh chứng cho quá trình cài đặt, cấu hình và kiểm tra Tailscale trên MGMT01 trong Tuần 3.

Bao gồm:

- Kết nối mạng của MGMT01
- Kiểm tra kết nối tới các máy chủ trong Lab
- Trạng thái Tailscale trên MGMT01
- Cấu hình Subnet Router
- Xác nhận subnet route `192.168.10.0/24` trên Tailscale Admin Console
- Kiểm tra kết nối từ Application Laptop vào mạng Lab thông qua MGMT01
