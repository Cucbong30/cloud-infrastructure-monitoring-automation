# Alertmanager Screenshots

Hình ảnh cho quá trình cài đặt, cấu hình và kiểm thử Alertmanager trên MON01 trong Tuần 3.

Bao gồm:

- Kiểm tra Alertmanager service và port `9093`
- Prometheus alert ở trạng thái `PENDING`
- Prometheus alert ở trạng thái `FIRING`
- Alertmanager nhận cảnh báo `InstanceDown`
- Alert trở về trạng thái `INACTIVE` sau khi WEB01 được khôi phục
